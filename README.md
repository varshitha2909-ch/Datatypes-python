## Description
  - This repository demonstrate the basic concepts and operations of list,tuple,set and dictionary data typs in python.

## Data types covered
 1 List
   - Ordered and mutable collection
   - Allows duplicate values
   - Supports indexing and slicing
    
 2 Tuple
   - Ordered and immutable collection
   - Allows duplicate values
   - Supports indexing and slicing

 3 Dictionary
   - Stores data in key-value pairs
   - Mutable
   - Keys must be unique

 4 Set
   - Unordered collection
   - Mutable
   - Does not allow duplicate values

## Language
  - Python

  - Slicing
  - Operations
